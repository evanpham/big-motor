# big-motor
Magnetic circuit analysis library for axial-flux SRM torque estimation

## Contents

- `basic_mag_analysis/`: magnetic-circuit (reluctance network) torque model.
- `elmer_fea/`: 3D finite-element analysis of one phase of the 40-pole ring-coil machine in Elmer, with design-variant results. See `elmer_fea/README.md`.
